# VCLI Workspace

This repository contains the VCLI developer tools. Each project owns its source, dependencies, build commands, and documentation.

## Projects

- [VCLI NestJS](vcli_nestjs/README.md) creates and maintains NestJS backends.

Run NestJS CLI development commands from `vcli_nestjs/`. See the [source build instructions](vcli_nestjs/README.md#build-from-source) to get started.
