# VCLI Workspace contributor instructions

Git is rooted here. Each VCLI project is maintained in its own directory.

- For the NestJS CLI, read [vcli_nestjs/AGENTS.md](vcli_nestjs/AGENTS.md) and [the task map](vcli_nestjs/START-HERE.md).
- Run project commands from the relevant project directory. For the NestJS CLI, use `vcli_nestjs/`.
