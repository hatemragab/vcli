# Private evaluation distribution

No public license or npm namespace ownership has been selected for VCLI. The current package is private and provided for owner-controlled local evaluation. Public distribution remains disabled until the owner chooses the license, namespace and release policy.

Public npm dependencies retain their respective licenses. VCLI imports those packages rather than vendoring their implementation. The expected-output reference and generated application code were created for this repository; no private product source, credentials or environment files are copied.
